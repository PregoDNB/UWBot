Privacy Policy

Last Updated: May 02, 2025

This Privacy Policy outlines how the translation bot ("Bot") collects, uses, and protects your information in compliance with Discord's Developer Terms of Service and applicable laws.

Information Collection

The Bot does not actively collect or store personal data such as email addresses, phone numbers, or user IDs beyond what is necessary to perform its intended function. The only data processed includes:





Message content sent in the Dutch or English channels for the purpose of translation.



Temporary usage data (e.g., character count) to manage API limits, which is stored locally and reset monthly.

This data is not shared with third parties unless required by law or with your explicit consent.

Purpose of Data Use





The Bot uses message content solely to provide real-time translations between Dutch and English.



Usage data is used to ensure compliance with DeepL and MyMemory API limits.

Data Retention





Message content is not stored long-term; it is processed in real-time and discarded immediately after translation.



Usage data is retained in a local file (usage.json) for the current month and reset at the start of each new month.

Data Security

The Bot employs basic security measures, including encryption of data in transit via Discord's infrastructure. No sensitive data is exposed, and access to the Bot's data is restricted to the developer.
